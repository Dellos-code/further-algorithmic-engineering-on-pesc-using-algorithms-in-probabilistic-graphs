\section*{Regime-adaptive rank fusion}
This chapter studies rank fusion of the frozen W1 score and two-iteration
message passing (MP2) in uncertain graphs.  The primary covariate is the mean
edge probability over existing edges, rather than a density that assigns zero
probability to non-edges.  Candidate functions were fitted only on the
development panel using the independent fitting sample; confirmation uses
fresh synthetic instances.

The frozen function is a clipped-linear function of the primary covariate.
On the fresh test panel the mean Spearman correlations are
\MeanF_g{} for the fusion, \MeanF_c0{} for the best constant, \MeanW1{}
for W1, and \MeanMP2{} for MP2.  These values are generated by
\texttt{make\_fusion\_assets.py}; no result number is typed in this document.

The evidence mode is synthetic because the recorded acquisition search
obtained only the bundled real networks.  Consequently these findings are
not results on a broad real-network benchmark.  Cluster-aware network-level
confirmation, expanded candidate families, and the remaining large fresh
panels are limitations of this experimental increment.
